# StandardOS Architecture

StandardOS is a conversational hospitality onboarding system built during the hackathon using:

- ElevenLabs Conversational AI
- Twilio Voice
- Prompt orchestration
- Knowledge-base driven onboarding
- Real-time conversational coaching

## Core Demo Features

- Live hospitality onboarding
- Guest arrival rehearsal
- Service recovery coaching
- Experience recommendation training
- Multilingual hospitality practice
- Real-time conversational feedback
- Front desk readiness evaluation

## Demo Scenario

A new Rosewood Sand Hill employee is onboarded through a live conversational session with an AI hospitality mentor named Remy.

The onboarding focuses on:
- emotional pacing
- guest reassurance
- experience curation
- multilingual hospitality
- consistent guest standards

## Vision

Train every employee to deliver the same guest experience.
